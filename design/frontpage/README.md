# Frontpage — σχέδια για την αρχική του billiardtoday.com

Εδώ κρατάμε τα σχέδια της αρχικής, ώστε να ανοίγουν από οποιονδήποτε υπολογιστή.
Είναι **αυτόνομα αρχεία HTML** — ανοίγουν με διπλό κλικ στον browser, χωρίς εγκατάσταση, χωρίς server.

## Τα αρχεία

| Αρχείο | Τι είναι |
|---|---|
| `frontpage-bt-cyan.html` | **Το τρέχον σχέδιο.** Σκελετός UMB (hero + 3 κάρτες + λωρίδα δεδομένων), ύφος snooker, χρώμα cyan του BT |
| `frontpage-bt-snooker.html` | Ίδιο ακριβώς σχέδιο με κόκκινο (χρώμα snooker) — για σύγκριση |
| `frontpage-spectator-a-live-desk.html` | Παλαιότερη εκδοχή Α: σκοτεινή, «ταμπλό δεδομένων» |
| `frontpage-spectator-b-editorial.html` | Παλαιότερη εκδοχή Β: ανοιχτή, περιοδική |
| `BRIEF-v3-events-and-stats.md` | Το brief που είχε δοθεί στα μοντέλα (Οκτ 2026) |
| `00-scoreboard-copy-outline.txt` | Το κείμενο για τη σελίδα πώλησης του scoreboard (25 Νοε 2026) |

## Τα δεδομένα μέσα είναι αληθινά

Λήψη: **27 Νοεμβρίου 2026**, από το ίδιο το site.

- `/api/tournaments` — διοργανώσεις (League 3 22–27/11, Bottrop U21 27–29/11 με 24 συμμετοχές, Μαδρίτη 5–7/2/2027, Σαλαμίνα 24–29/3/2027)
- `/api/rankings/btr` — κατάταξη BTR, 2.745 βαθμολογημένοι (CHO 1890.4, JASPERS 1808.8, ZANETTI 1788.8, MERCKX 1787.0, BAO 1786.8)
- `/news` — τίτλοι και φωτογραφίες από το CDN μας
- Carom Café Fall Classic 18–22/11: 55 παίκτες, 182 + 60 + 7 αγώνες, καλύτερος μέσος όρος 1.506

Όταν περαστεί στον κώδικα, **κανένα νούμερο δεν μένει στατικό** — όλα έρχονται από τη βάση.

## Ανοιχτή απόφαση

**Κόκκινο** (ύφος snooker, 6.5:1 αντίθεση) ή **cyan** (δικό μας χρώμα, 12:1 στα κουμπιά).
Δεν έχει αποφασιστεί ακόμα.

## Πώς ανοίγει από άλλον υπολογιστή

```
git clone https://github.com/makpapad/billiardtoday-frontend
```

και άνοιγμα του HTML αρχείου. Για το ίδιο το site χρειάζεται `npm install` και `.env` (βλ. `DEPLOYMENT.md`).

> Τα πλήρη πειράματα (10 μοντέλα, logs, παλιά mockups) μένουν τοπικά στον φάκελο `.hermes/mockups/`
> και δεν ανεβαίνουν στο repo — είναι μεγάλα και δεν χρειάζονται.
