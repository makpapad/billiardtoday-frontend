# Project Overview

Workspace:
- `1-billiards-strapi`
- `2-billiardtoday-admin`
- `3-BilliatdToday-Scoreboard`
- `4-billiardtoday-frontend`

Κύριος στόχος αυτού του κύκλου:
- ανάπτυξη εμπορικής διαχείρισης για καταστήματα μπιλιάρδου

Κεντρική λογική:
- το Strapi κρατά τα business entities και τα configuration δεδομένα
- το admin είναι το βασικό λειτουργικό περιβάλλον διαχείρισης
- ό,τι εμφανίζεται στο UI πρέπει να είναι μεταφράσιμο σε ελληνικά και αγγλικά

Βασικές επιχειρησιακές ανάγκες:
- διαχείριση τραπεζιών
- χρέωση χρόνου παιχνιδιού
- ανοιχτές καρτέλες πελατών
- παραγγελίες προϊόντων
- πληρωμές και ανοιχτά υπόλοιπα
- πίστωση πελατών
- ρυθμίσεις τιμολόγησης και πολιτικών λειτουργίας

Μελλοντικές επεκτάσεις:
- αυτοματισμός φωτισμού ανά τραπέζι
- παραγγελιοληψία από τραπέζι με tablet ή QR
- multi-branch και μεγαλύτερα καταστήματα
