# Working Rules

Κανόνες για όποιον δουλεύει το workspace:

1. Πριν από νέα υλοποίηση, έλεγξε αν η ίδια απόφαση υπάρχει ήδη στο `03-decisions.md`.
2. Αν αλλάξει ο επιχειρησιακός κανόνας, ενημέρωσε πρώτα τη μνήμη και μετά τον κώδικα.
3. Κάθε νέο UI label πρέπει να είναι μεταφράσιμο.
4. Απέφυγε hardcoded εμπορική λογική μέσα στις σελίδες.
5. Αν ολοκληρωθεί ένα σημαντικό feature, ενημέρωσε το `02-current-state.md`.
6. Αν αλλάξουν οι προτεραιότητες, ενημέρωσε το `04-next-steps.md`.

Ελάχιστο ritual ενημέρωσης μετά από κάθε σημαντικό βήμα:
- τι ολοκληρώθηκε
- τι έμεινε ανοιχτό
- ποια απόφαση άλλαξε
