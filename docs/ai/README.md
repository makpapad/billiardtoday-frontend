# AI Workspace Memory

Κοινός φάκελος μνήμης για το BilliardToday workspace.

Σκοπός:
- να υπάρχει ένα σταθερό σημείο αναφοράς για όλους τους agents και υπολογιστές
- να καταγράφονται αποφάσεις, τρέχουσα κατάσταση και επόμενα βήματα
- να μειώνεται η απώλεια context ανάμεσα σε διαφορετικές συνεδρίες εργασίας

Βασικά αρχεία:
- `01-project-overview.md`
- `02-current-state.md`
- `03-decisions.md`
- `04-next-steps.md`
- `05-working-rules.md`

Προτεινόμενη χρήση:
1. Πριν ξεκινήσει εργασία, διάβασε `02-current-state.md` και `03-decisions.md`.
2. Αν αλλάξει η κατεύθυνση του project, ενημέρωσε πρώτα το `03-decisions.md`.
3. Αν ολοκληρωθεί ένα σημαντικό βήμα, ενημέρωσε `02-current-state.md` και `04-next-steps.md`.

Σημείωση:
Ο φάκελος αυτός είναι κοινός μέσα στο workspace, αλλά για να συγχρονίζεται μεταξύ διαφορετικών υπολογιστών πρέπει να περιλαμβάνεται σε backup, git ή άλλη λύση sync.
