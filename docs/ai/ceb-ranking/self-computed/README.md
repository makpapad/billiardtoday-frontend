## Εκκρεμότητες (γνωστές, μικρές)

1. **Ταυτοποίηση παικτών**: ελληνικά ονόματα στη βάση μας είναι με ελληνικό αλφάβητο (`greek_translit.py` τα μεταγράφει), μερικά ονόματα με αντίστροφη σειρά (`GLENN Hofman` / `HOFMAN Glenn`) και **διπλές εγγραφές** παίκτη.
2. **9 ποινές −4** — χειροκίνητη λίστα.
3. **Το «άθροισμα» του PDF**: η CEB μετράει 7 από τα 8 (6 WC + 1 EC + 1 εθνικό, πετάει το χειρότερο). Τα B/C/D (εθνικά) είναι χειροκίνητα (367 νούμερα).
4. **Διπλότυπο τουρνουά**: το `world-cup-3-cushion-porto-matosinhos-2026` (χωρίς αγώνες) και `...-2026-undefined` (με τα 149 αποτελέσματα). Η σελίδα της κατάταξης δείχνει το πρώτο → χωρίς αποτελέσματα.
