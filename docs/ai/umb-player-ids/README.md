# UMB ID — μητρώο και ταίριασμα με τους παίκτες μας

Σκοπός: κάθε παίκτης στο `bt-players` να έχει το **UMB ID** του, ώστε η σύνδεση με τις λίστες
(CEB, UMB, ομοσπονδίες) να γίνεται με **ID** και όχι με μαντεψιά στο όνομα.

## Γιατί με ID

Το «Player ID» που στέλνουν οι ομοσπονδίες **είναι** το UMB ID. Επιβεβαιώθηκε πάνω στα αρχεία
Δανίας/Νορβηγίας (`docs/ai/ceb-ranking/national/`):

| ID | Λέει η UMB | Λέει το αρχείο της ομοσπονδίας | |
|---|---|---|---|
| 0273 | KNUDSEN Brian [DK] | Brian Knudsen | ✓ |
| 0615 | SCHRODER Allen [DK] | Allan Schrøder | ✓ λύνει την ορθογραφία |
| 3650 | OZCAN Gazi [NO] | OZKAN Gazi | ✓ λύνει το OZKAN/OZCAN |
| 3250 | MELING Sebastian [NO] | Sebastian Meling | ✓ |

## Τι κάνει

| Αρχείο | Ρόλος |
|---|---|
| `parse_umb_ranking.py` | διαβάζει ένα PDF λίστας της UMB -> `rank, name, fed, Player ID` |
| `fetch_umb_rankings.py` | κατεβάζει τις λίστες (ευρετήριο + αρχείο εκδόσεων) και χτίζει το μητρώο |
| `match_players.py` | ταιριάζει το μητρώο με τους `bt-players` -> λίστες γεμίσματος/ελέγχου |

```bash
cd docs/ai/umb-player-ids
uv run --python 3.12 --with pymupdf  python fetch_umb_rankings.py            # χτίζει/ενημερώνει το μητρώο
uv run --python 3.12 --with openpyxl python match_players.py --xlsx          # ταιριάζει, βγάζει xlsx
```

* `.cache/` = τα κατεβασμένα PDF (δεν μπαίνουν στο git). `--refresh` τα ξανακατεβάζει.
* `--rebuild` ξεκινά από άδειο μητρώο (όταν αλλάξει κανόνας).
* `--extra <url|path>` προσθέτει PDF που δεν είναι ακόμη στο ευρετήριο (π.χ. νεότερη έκδοση που
  βγήκε αλλά δεν έχει μπει στη σελίδα `ranking/archive`).

## Έξοδοι

| Αρχείο | Τι είναι |
|---|---|
| `data/umb-ids.json` | το μητρώο: `umb_id -> {name, fed, editions[]}`, με `meta.conflicts` |
| `data/match-fill.json` | παίκτης μας -> UMB ID, ασφαλές (μοναδικό, επίθετο+όνομα, ίδια χώρα) |
| `data/match-review.json` | θέλει μάτι: διφορούμενο, ίδιο επίθετο, χώρα που δεν ταιριάζει, διπλό ID |
| `data/match-none.json` | δεν βρέθηκε σε καμία λίστα UMB (κυρίως τοπικοί παίκτες) |
| `data/umb-id-match.xlsx` | τα τρία παραπάνω σε φύλλα, με φίλτρα, για ανθρώπινο έλεγχο |

## Κανόνες (ποτέ λάθος σύνδεσμος)

1. **Επίθετο υποχρεωτικό.** Ταίριασμα με κοινό μικρό όνομα (Dimitrios, Konstantinos, Sang) βγάζει
   σκουπίδια — δεν μετράει. Το επίθετο είναι το πρώτο συνθετικό στο όνομα της UMB.
2. **Ίδια χώρα.** Αν το `fed` της UMB διαφέρει από τη χώρα του παίκτη μας -> έλεγχος, όχι αυτόματο.
3. **Διπλά IDs.** Το μητρώο έχει σήμερα **29 IDs με δύο διαφορετικά επώνυμα** — δικό τους λάθος
   στη λίστα (π.χ. `3185` δίνεται και σε KNUDSEN Thomas [DK] και σε EGGERS Jens [DE]).
   Αυτά τα IDs **δεν** χρησιμοποιούνται αυτόματα, πάνε στον έλεγχο.
4. **Ένα ID σε δύο δικούς μας παίκτες** -> πίσω στον έλεγχο (δείχνει διπλή καρτέλα).
5. Το ID αποθηκεύεται **κείμενο 4 ψηφίων με μηδενικά** (`0364`, όχι `364`).

## Ευρήματα

* Το ευρετήριο της UMB (`/ranking`, `/ranking/archive`) έχει **183 PDF**· οι 4 τρέχουσες λίστες
  (WorldPlayers, WorldLadies, WorldJuniors, UMBEvents) δίνουν **4.261 IDs**.
* Οι παλιότερες εκδόσεις προσθέτουν 0-3 IDs — η κάλυψη είναι ήδη πλήρης, δεν χρειάζεται
  κατέβασμα 183 αρχείων.
* Η έκδοση WorldPlayers **23/2026** (το PDF που μας έστειλαν) δεν είναι ακόμη στο ευρετήριο:
  μπαίνει με `--extra`.
* Η σελίδα `/athletes` της UMB είναι άδεια («No athletes available») — δεν υπάρχει δημόσιο μητρώο.
