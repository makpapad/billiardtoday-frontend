# ❓ Συχνές Ερωτήσεις (FAQ)

## Γενικές Ερωτήσεις

### Τι είναι το BilliardToday;
Το BilliardToday είναι μια πλατφόρμα για live scoring, διαχείριση clubs, τουρνουά και live streaming αγώνων μπιλιάρδου.

### Χρειάζομαι ειδικό λογισμικό;
Όχι. Το BilliardToday τρέχει εξ ολοκλήρου μέσω browser. Για το scoreboard υπάρχει και desktop εφαρμογή (Electron) για Windows και Android app.

### Είναι δωρεάν;
Εξαρτάται από το πλάνο του club σου. Ρώτα τον διαχειριστή σου.

## Scoreboard (Διαιτητής)

### Πώς ξεκινάω ένα νέο match;
1. Άνοιξε το scoreboard
2. Επίλεξε "Νέος Αγώνας"
3. Διάλεξε τους δύο παίκτες
4. Ρύθμισε τις παραμέτρους (format, χρονόμετρο)
5. Πάτα "Έναρξη"

### Πώς αλλάζω το σκορ κατά τη διάρκεια του αγώνα;
Χρησιμοποίησε τα κουμπιά + και - δίπλα από το σκορ του κάθε παίκτη, ή τα keyboard shortcuts (διάστημα = πόντος, Backspace = διόρθωση).

### Τι κάνω αν έκανα λάθος στο σκορ;
Μπορείς να πατήσεις **Undo** (ή Ctrl+Z) για να αναιρέσεις την τελευταία ενέργεια.

### Πώς ξεκινάω το streaming;
Δες τον [Οδηγό Streaming](user-guides/streaming).

## Admin Dashboard (Διοργανωτής)

### Πώς προσθέτω νέο παίκτη;
1. Πήγαινε στο **Παίκτες** στο sidebar
2. Πάτα **"Προσθήκη Παίκτη"**
3. Συμπλήρωσε τα στοιχεία (όνομα, επίθετο, email, club)
4. Πάτα **"Αποθήκευση"**

### Πώς δημιουργώ τουρνουά;
1. Πήγαινε στο **Τουρνουά**
2. Πάτα **"Νέο Τουρνουά"**
3. Όρισε όνομα, ημερομηνίες, format, παίκτες
4. Πάτα **"Δημιουργία"**

### Πώς βλέπω τα στατιστικά ενός παίκτη;
Πήγαινε στο προφίλ του παίκτη → καρτέλα **"Στατιστικά"**. Θα δεις:
- Μέσο όρο (average)
- High run
- Ποσοστά νικών
- Ιστορικό αγώνων

### Ξέχασα τον κωδικό μου — τι κάνω;
Πάτα **"Ξέχασα τον κωδικό"** στη σελίδα login. Θα λάβεις email επαναφοράς.

## Live Παρακολούθηση (Θεατής)

### Πώς βλέπω έναν αγώνα live;
1. Μπες στο `billiardtoday.com`
2. Στην αρχική θα δεις τα **Live Τώρα** matches
3. Κάνε κλικ σε όποιο θέλεις
4. Θα δεις το live scoreboard και (αν υπάρχει) το video stream

### Μπορώ να δω παλιούς αγώνες;
Ναι. Μπες στο προφίλ ενός club ή παίκτη και δες το **Ιστορικό Αγώνων**.

### Γιατί δεν παίζει το video;
Πιθανοί λόγοι:
- Ο αγώνας δεν έχει ξεκινήσει ακόμα streaming
- Ο browser σου δεν υποστηρίζει τον video player — δοκίμασε Chrome ή Edge
- Το δίκτυό σου μπλοκάρει τα video streams — δοκίμασε από άλλο WiFi

## Streaming

### Τι εξοπλισμό χρειάζομαι για streaming;
- **Κάμερα** (webcam, DSLR/mirrorless με capture card, ή IP camera)
- **Υπολογιστής** που τρέχει το scoreboard (για RTMP/WHIP streaming)

### Ποια πρωτόκολλα υποστηρίζονται;
- **RTMP** — για κάμερες και εξωτερικούς encoders
- **RTSP** — για IP κάμερες
- **WHIP (WebRTC)** — απευθείας από τον browser

### Πόσο bandwidth χρειάζεται;
Τουλάχιστον 2 Mbps upload για SD ποιότητα, 5 Mbps για HD.
