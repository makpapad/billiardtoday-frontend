# BilliardToday — Documentation

Καλώς ήρθες στο documentation του **BilliardToday** — την πλατφόρμα διαχείρισης αγώνων μπιλιάρδου.

## 🎯 Τι είναι το BilliardToday;

Το BilliardToday είναι μια ολοκληρωμένη πλατφόρμα για:
- **Live scoring** αγώνων μπιλιάρδου σε πραγματικό χρόνο
- **Διαχείριση** clubs, παικτών, τουρνουά και διοργανώσεων
- **Live streaming** αγώνων με πολλαπλούς τρόπους μετάδοσης
- **Παρακολούθηση** αγώνων από θεατές online

## 📚 Οδηγοί ανά ρόλο

| Ρόλος | Οδηγός | Περιγραφή |
|-------|--------|-----------|
| 🎱 **Διαιτητής** | [Οδηγός Scoreboard](user-guides/referee-scoreboard) | Πώς στήνεις και διαχειρίζεσαι έναν αγώνα |
| 🏢 **Διοργανωτής** | [Οδηγός Admin Dashboard](user-guides/organizer-admin) | Διαχείριση clubs, παικτών, τουρνουά |
| 👀 **Θεατής** | [Οδηγός Live Παρακολούθησης](user-guides/spectator-frontend) | Πώς βλέπεις live αγώνες και stats |
| 🎥 **Χειριστής Κάμερας** | [Οδηγός Streaming](user-guides/streaming) | Πώς κάνεις stream έναν αγώνα |
