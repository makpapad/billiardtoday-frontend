# WordPress Themes for BilliardToday

Αυτή η δομή περιέχει 8 WordPress themes που αντιστοιχούν στα Next.js landing pages.

## Δομή Φακέλων

```
wordpress/
├── README.md
├── themes/
│   ├── billiardtoday-original/
│   ├── billiardtoday-original-light/
│   ├── billiardtoday-new/
│   ├── billiardtoday-light/
│   ├── billiardtoday-minimal/
│   ├── billiardtoday-dark-modern/
│   ├── billiardtoday-corporate/
│   └── billiardtoday-sport-fun/
├── switcher/
│   ├── theme-switcher.php
│   ├── switcher.css
│   └── switcher.js
└── assets/
    ├── shared/
    │   ├── css/
    │   ├── js/
    │   └── images/
    └── fonts/
```

## Themes

1. **Original** - Dark theme με neon effects
2. **Original Light** - Ανοιχτόχρωμη εκδοχή του original
3. **New** - Modern gradient design με purple/pink
4. **Light** - Clean και bright design
5. **Minimal** - Ultra-minimalist design
6. **Dark Modern** - Black background με bold typography
7. **Corporate** - Professional enterprise design
8. **Sport Fun** - Colorful και playful design

## Χρήση

1. Αντιγράψτε το επιθυμητό theme στον WordPress φάκελο `wp-content/themes/`
2. Ενεργοποιήστε το theme από το WordPress admin
3. Για τον switcher, αντιγράψτε τον φάκελο `switcher/` στο root theme

## Συμβατότητα

- WordPress 6.0+
- PHP 8.0+
- Responsive design
- Multi-language support (WPML compatible)
